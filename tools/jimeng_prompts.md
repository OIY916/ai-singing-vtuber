# 即梦（Seedance）生成大肥鱼动态素材 —— 提示词与参数

## 一、先上传哪张图

| 文件 | 尺寸 | 什么时候用 |
|---|---|---|
| `avatar/jimeng/jimeng_front_9x16_green.png` | 720×1280 | **首选**。竖屏、纯绿背景、单人 |
| `avatar/jimeng/jimeng_front_green.png` | 440×625 | 想保留原始比例时用 |
| `avatar/jimeng/jimeng_front_9x16_white.png` | 720×1280 | 万一绿幕把裙子边缘染绿了，换这张 |

⚠️ **绝对不要用三视图那张**。一帧里三个人，模型会让人物互相打架；
而且 3:1 的宽幅丢进 16:9/9:16 的模板会被拉伸变形。

## 二、即梦里怎么设

1. 进 **视频生成** → 选 **图生视频**
2. 上传 `jimeng_front_9x16_green.png`
3. 模式选 **首帧**（不是"参考图"—— 首帧才是"从这张图开始动"）
4. 比例选 **9:16**
5. 时长 **越长越好**（8-10 秒）；后面我会截取最稳的一段做循环

## 三、提示词（直接复制）

### 1️⃣ idle 待机（最重要，占 90% 的直播时间）

```
角色保持站立姿势不动，仅做细微的呼吸起伏：肩膀和胸口随呼吸缓缓起伏，头部极轻微上下浮动。头发和裙摆随呼吸轻微摆动。眼睛每隔几秒自然眨一下。表情平静温和。镜头完全固定，不移动不缩放不旋转。绿幕背景保持完全静止不动。
```

**要点**：
- 「仅做细微」——不写这句，模型会让你的人物大幅跳舞
- 「镜头完全固定」——运镜是循环的最大敌人
- 「绿幕保持静止」——否则抠图后背景会有残影

### 2️⃣ speak 说话

```
角色站在原地说话，头部自然小幅点头和轻微侧转，嘴巴有开合动作。一只手偶尔做很小的手势。头发和裙摆轻微摆动。表情生动自然。镜头完全固定，不移动不缩放。绿幕背景保持完全静止不动。
```

**要点**：
- 「小幅」「很小的手势」——幅度大就会像在演讲
- 不要写"挥手"，那会让整只手抬起来，循环接不上

### 3️⃣ sing 唱歌

```
角色站立唱歌，身体随节奏轻微左右摆动，头部小幅晃动，嘴巴持续开合。头发和裙摆随动作摆动得略大一些。表情投入愉悦。镜头完全固定，不移动不缩放。绿幕背景保持完全静止不动。
```

**要点**：
- 「轻微」「小幅」——比 idle 大一点，但远不到跳舞
- 不要写具体节拍，我们的页面会用自己的频谱数据驱动律动

## 五、生成后检查这几条

拿到视频先看一遍，任何一条不满足就重生成：

| 检查项 | 不合格的表现 |
|---|---|
| 人物还是不是那个样子 | 脸变了、发型变了、裙子颜色变了 → **最严重**，直接弃用 |
| 脚有没有动 | 脚在原地滑动 → 循环时会"溜冰" |
| 镜头有没有漂移 | 画面缓慢平移/放大 → 循环必断 |
| 绿幕纯不纯 | 背景有其他颜色、有阴影 → 抠图会有残影 |
| 首尾帧接近吗 | 开头和结尾姿态差很远 → 循环会"卡一下" |

**最容易翻车的是前两条**。人物一致性上，即梦对"图生视频"比"文生视频"好很多，但仍有概率让角色逐渐变形。所以**时长不要贪长**，8 秒比 15 秒更安全（越长越容易漂）。

## 七、拿到视频后我做什么（你不用管）

1. **自动找循环点**：在视频里搜索"首尾帧最相似"的位置，只截那一段循环，避免接缝跳动
2. **抠绿幕**：逐帧抠掉绿色，输出透明背景的 webm
3. **接进直播间**：`avatar.html` 用 `<video>` 叠在现在的位置，按状态（idle/speak/sing）切换
4. **兜底**：视频加载失败时自动退回现在的静态图 + CSS 动画，直播不会黑屏

## 八、成本提醒

页面上现在写着 **Seedance 2.5 ￥0.18/秒**。按 8 秒一段、三段算：

```
3 段 × 8 秒 × 0.18 = ￥4.32
```

算上可能要重跑 2-3 次挑好的，**总共大概 10-15 块**。年会员可能有免费额度，先用那个。

**建议先只生成 idle 一段试水**。idle 占直播 90% 时间，效果最影响观感。确认人物没变形、循环能接上，再生成另外两段。
